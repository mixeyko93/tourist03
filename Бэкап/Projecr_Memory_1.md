Технологии

Python 3.12

FastAPI + uvicorn (бэкенд)

HTML/CSS/JS фронт (Leaflet + MarkerCluster для карты)

Telegram WebApp (aiogram для бота)

Структура проекта
app.py                 ← FastAPI + API
/web/index.html        ← фронт для пользователей (карта, брони, услуги, помощь)
/web/styles.css        ← стили фронта
/web/app.js            ← логика фронта
/web/admin-camps.html  ← отдельная страница админки баз
/web/admin-bot.html    ← отдельная страница админки бота

Пользовательский интерфейс

Главная карта

Leaflet (OpenStreetMap)

вкладки снизу: Карта / Брони / Услуги / Помощь

кастомные маркеры «домик» вместо точек

попапы: фото, название, озеро, цена, телефон, кнопки Подробнее и Забронировать

Панель фильтра (открывается FAB-кнопкой)

даты: Заезд / Выезд

степперы: Взрослые, Дети

кнопки: Показать, Сбросить

текст сверху: «Заполните данные для поиска баз по параметрам»

Сброс фильтра: очищает даты, возвращает Взрослые=1, Дети=0, показывает все базы

Автоскрытие панели фильтра:

при смене вкладки

при клике по карте

при открытии попапа базы

Панель доступности: выезжает снизу, показывает список номеров на выбранные даты

Другие вкладки:

/admin-bot.html — управление ботом (учётные записи, пока примеры в памяти)

Раздача фронта через FastAPI

В app.py:

from fastapi.staticfiles import StaticFiles
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
WEB_DIR = BASE_DIR / "web"

app = FastAPI()

# API-роуты: /api/camps, /api/availability, /api/bookings, ...

# раздача фронта
app.mount("/", StaticFiles(directory=WEB_DIR, html=True), name="web")


Теперь:

http://127.0.0.1:8080/ — пользовательский фронт

http://127.0.0.1:8080/admin-camps.html — админ баз

http://127.0.0.1:8080/admin-bot.html — админ бота
