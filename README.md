# 🌲 Tourist03 — веб-платформа бронирования баз отдыха

**Tourist03** — это веб-приложение для поиска и бронирования баз отдыха и туристических объектов.
Создано для удобной работы администраторов баз и клиентов.

---

## 🚀 Технологии

* **Backend:** FastAPI
* **Frontend:** HTML + TailwindCSS + JavaScript
* **База данных:** SQLite (`camps.db`, `users.db`)
* **Язык программирования:** Python 3.11+

---

## 🗂️ Структура проекта

```
Tourist03_win/
├── app.py                # Основной сервер FastAPI
├── bot.py                # Телеграм-бот для уведомлений
├── db/
│   ├── camps.db          # БД с базами отдыха
│   └── users.db          # БД с пользователями
├── static/
│   ├── styles.css        # Стили интерфейса
│   ├── app.js            # Основная логика клиента
│   └── ui.js             # Вспомогательные функции UI
├── templates/
│   ├── index.html        # Главная страница
│   ├── admin-base.html   # Интерфейс администратора
│   └── superadmin.html   # Интерфейс супер-админа
└── requirements.txt      # Зависимости проекта
```

## ⚙️ Установка и запуск (локально)

1. Клонируй репозиторий:

   ```bash
   git clone https://gitflic.ru/project/mixeyko/tourist03.git
   cd tourist03
   ```

2. Создай виртуальное окружение:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запусти приложение:

   ```bash
   uvicorn app:app --reload --port 8080
   ```

5. Открой браузер:

   ```
   http://127.0.0.1:8080
   ```
