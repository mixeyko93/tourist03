# VK-бот Tourist03

VK-бот запускается отдельным процессом и не заменяет Telegram-бота.

## Переменные окружения

Добавьте в серверный `.env`:

```env
VK_TOKEN=ваш_токен_сообщества_vk
VK_GROUP_ID=238079255
TOURIST_WEBAPP_URL=https://turist03.ru
```

Если `TOURIST_WEBAPP_URL` не задан, бот попробует использовать существующий `WEBAPP_URL`.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python vk_bot.py
```

Для продакшена запускайте `vk_bot.py` отдельным `systemd`-сервисом или отдельным процессом рядом с текущим Telegram-ботом.

Готовый пример systemd-сервиса находится в `deploy/systemd/tourist03-vk-bot.service`.
После установки сервиса штатный `./deploy.sh` будет пытаться перезапускать `tourist03-vk-bot` вместе с остальным продом.

## Настройки VK

В настройках сообщества VK включите:

- Сообщения сообщества.
- Возможности ботов.
- Long Poll API.
- Тип события: `Входящее сообщение`.

## Логика

VK-бот повторяет клиентскую часть Telegram-бота:

- приветствие;
- команду `Начать` или `/start`;
- команду `Помощь` или `/help`;
- клавиатуру с кнопкой открытия приложения `https://turist03.ru`.

CRM-бот уведомлений, привязки сотрудников, события и согласования в VK пока не перенесены.
