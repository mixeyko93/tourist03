# Подложка Яндекс Карт

Все Leaflet-карты проекта используют официальный Yandex Maps Tiles API через
`static/map-tiles.js`. Запросы отправляются только на официальный endpoint
`https://tiles.api-maps.yandex.ru/v1/tiles/` с параметром
`projection=web_mercator`, совместимым с координатной сеткой Leaflet.

## Настройка ключа

1. Создайте ключ для **Tiles API** в [Кабинете разработчика Яндекса](https://developer.tech.yandex.ru/).
2. В настройках ключа укажите разрешённый домен `turist03.ru`. По документации
   Яндекса это ограничение автоматически включает поддомены. Для отдельного
   staging-домена добавьте его отдельной строкой.
3. Добавьте ключ только в приватный production env:

   ```dotenv
   YANDEX_MAPS_TILES_API_KEY=полученный_ключ
   ```

4. Перезапустите приложение штатным деплоем. Активация ключа и изменений его
   ограничений у Яндекса может занимать до 15 минут.

Ключ передаётся странице через runtime-конфигурацию
`window.__TOURISTIKA_MAPS__`. Это браузерный ключ: пользователь технически может
увидеть его в HTML и запросах. Поэтому защита строится на ограничении ключа по
домену и типу Tiles API, а не на попытке скрыть строку в JavaScript.

## Fallback и атрибуция

При наличии ключа основной слой — Яндекс Карты. При первой ошибке тайла слой
целиком снимается, официальный логотип Яндекса удаляется и подключается один
резервный слой OpenStreetMap с его атрибуцией. Одновременного наложения двух
подложек нет. Если ключ не задан, локальная разработка сразу использует OSM.

При активном слое Яндекса в левом нижнем углу показывается кликабельный
официальный логотип из комплекта Tiles API. Не изменяйте и не скрывайте его.

## CSP

В приложении и `deploy/Caddyfile` сейчас нет Content-Security-Policy. Если CSP
будет добавлена позже, для этой интеграции достаточно разрешить
`https://tiles.api-maps.yandex.ru` в `img-src`. Новых `script-src`, `style-src`
или `connect-src` для Tiles API не требуется: код и логотип обслуживаются с
домена Туристики.

## Ручная проверка после установки ключа

- открыть `/` и `/map` в desktop и мобильном браузере;
- проверить drag, колесо, double tap и pinch zoom;
- открыть маркер и кластер, геолокацию, фильтры, поиск, `flyTo` и `fitBounds`;
- проверить возврат на карту и восстановление её положения;
- повторить в Telegram WebApp на iOS и Android;
- убедиться в Network, что запросы к `tiles.api-maps.yandex.ru` отвечают 200,
  OSM не загружается, а в консоли нет ошибок;
- временно заблокировать Yandex Tiles и убедиться, что остаётся только OSM с
  корректной атрибуцией.
