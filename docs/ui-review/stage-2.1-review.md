# Этап 2.1 — визуальное ревью public UI

Дата проверки: 2026-07-16. Сценарий запускается командой
`python scripts/capture_public_ui_review.py` и использует приложение, реальные
brand-файлы `static/brand/turistika-icon.svg` и fixture публичного API
`tests/fixtures/public-camps.json`. Production-БД и production-каталог в нём не
используются.

## Как открыть материалы PR

После выполнения workflow **Public UI review** в PR #4 скачайте artifact
`public-ui-review` из блока **Artifacts** в запуске GitHub Actions и откройте
`index.html` из архива. В нём собраны все PNG и `review-metrics.json`.

Набор содержит:

- Desktop 1440×1000: `desktop-first-screen.png`, `desktop-hero.png`,
  `desktop-map.png`, `desktop-map-popup.png`, `desktop-information.png`,
  `desktop-footer.png`, `desktop-full-page.png`.
- Mobile 390×844: `mobile-first-screen.png`, `mobile-hero.png`,
  `mobile-menu.png`, `mobile-map.png`, `mobile-map-popup.png`,
  `mobile-information.png`, `mobile-footer.png`, `mobile-full-page.png`.

## Визуальная проверка

| Проверка | Desktop | Mobile |
| --- | --- | --- |
| Layout | Компактный sticky header, hero 410 px, затем сразу heading карты и Leaflet-карта; информационные секции и footer остаются ниже карты и не перекрываются. | Header 69 px, hero 360 px и одна CTA в одну колонку; canvas карты уже виден на первом экране, карточки и footer не дают горизонтальной прокрутки. |
| Меню | Ссылки `Главная`, `Карта`, `О проекте` доступны в header. | Кнопка открывает drawer ниже header; у него три ссылки. Нажатие `Карта` закрывает drawer и ведёт к карте. |
| Логотип и слоган | Используется `/static/brand/turistika-icon.svg`, текст — «Туристика», слоган — «Твоя карта впечатлений.». | Те же asset, название и слоган; логотип не является старым «Турист_03». |
| Карта | Карта — центральный блок сразу после hero: высота 700 px, три fixture-точки, более лёгкая рамка и тень. | Карта имеет 600 px; controls не перекрывают поисковую строку. |
| Popup | Клик по видимому marker открывает Leaflet popup поверх карты и пишет выбранное место в status; layout страницы не сдвигается. | То же поведение; проверяется клик по marker внутри видимой части карты. |
| Empty / ошибка | Пустой fixture: «Каталог пока наполняется — скоро здесь появятся новые места.». Ошибка API: «Не удалось загрузить каталог. Попробуйте обновить страницу.». | Используется тот же публичный map-модуль и те же состояния. |
| Без Telegram | `window.Telegram` отсутствует; публичная страница, карта и screenshots работают без console/page errors. | То же. |

Поиск намеренно фильтрует только уже загруженные `/api/camps` точки: после пустого
запроса показывает «Ничего не нашли. Попробуйте другой запрос.». Он не заявляет
о полнотекстовом или внешнем каталоге. На странице нет кнопок бронирования,
входа или регистрации при выключенных feature flags.

Footer не содержит 404-ссылок: два информационных пункта ведут к существующему
`#legal-note`, «Контакты» — на `https://t.me/tourist_03_bot`. Это рабочие
переходы, но ссылки на соглашение и политику пока являются якорями, а не
опубликованными юридическими страницами — их содержимое не следует считать
заменой будущих документов.

## Измерение «карта прежде всего»

Замеры сделаны после загрузки страницы в Playwright. `До первого пикселя карты`
— прокрутка от верхней позиции до появления canvas; `до карты под header` —
прокрутка, при которой верх canvas оказывается ниже sticky header. Скрипт
проверяет целевые пороги автоматически: canvas не ниже 650 px и не менее 350 px
карты в desktop viewport; не ниже 580 px и не менее 200 px карты в mobile.

| Метрика | До переработки desktop | После переработки desktop 1440×1000 | До переработки mobile | После переработки mobile 390×844 |
| --- | ---: | ---: | ---: | ---: |
| Высота header | 85 px | 77 px | 73 px | 69 px |
| Top hero / высота hero | 85 / 706 px | 77 / 410 px | 73 / 733 px | 69 / 360 px |
| Начало map section | 791 px | 487 px | 806 px | 429 px |
| Top canvas карты | 1104 px | **640 px** | 1109 px | **557 px** |
| Карты видно на первом экране | 0 px | **360 px** | 0 px | **287 px** |
| До первого пикселя карты | 104 px | **0 px** | 265 px | **0 px** |
| До карты под sticky header | 1019 px | 563 px | 1036 px | 488 px |

Итог: canvas поднят на 464 px в desktop и на 552 px в mobile. Hero с header
занимают 487 px (48,7% desktop viewport) и 429 px (50,8% mobile viewport).
Карта является частью первого экрана в обоих вариантах, а преимущества и
информационные блоки сохранены ниже неё. CTA «Открыть карту» остаётся одним
действием и прокручивает к началу секции, хотя карта уже видна без прокрутки.
Это переводит первое впечатление из landing page в map-first hybrid, не убирая
бренд, заголовок, описание и слоган.

## SEO и домен

`canonical`, `og:url`, `og:image`, `/robots.txt` и `/sitemap.xml` формируются
из `PUBLIC_BASE_URL`; в template и статических SEO-файлах домен не захардкожен.
Сценарий проверяет это с `https://review.turistika.example`. В deployment example
по-прежнему задан `PUBLIC_BASE_URL=https://turist03.ru` как конфигурационное
значение. Проверить доступность `https://turist03.ru` из этой среды не удалось:
TLS-соединение завершилось `SSL_ERROR_SYSCALL`; утверждать, что домен сейчас
доступен публично, на основании этой проверки нельзя.
