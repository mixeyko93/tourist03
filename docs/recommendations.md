# Рекомендации и nearby

Рекомендации детерминированы и не используют ML или персональную историю.
Конфигурируемые веса учитывают kind/type/subtype, общие tags/amenities,
region/city, расстояние, общую подборку/маршрут, editorial boost и freshness.
Текущая и непубличные сущности исключаются до scoring.

Public API возвращает понятную причину (`Рядом`, `Похожий тип`,
`По этой теме`, `В этой подборке`, `В этом маршруте`, `В этом регионе`), но
не numeric score. Один и тот же вход даёт стабильный порядок с id tie-breaker.

Nearby сначала ограничивает запрос bbox, затем считает Haversine только для
кандидатов. Радиусы: 5/10/25/50/100 км. PostGIS не нужен. Точные координаты
используются для одного запроса и не сохраняются; отказ геолокации ведёт к
ручной точке, городу или общей карте.
