# Туристика: логотипы

- `turistika-logo-horizontal.svg` - основной логотип: знак + текст.
- `turistika-logo-horizontal-dark.svg` - версия для темного фона.
- `turistika-logo-stacked.svg` - вертикальная версия для презентаций и экранов приветствия.
- `turistika-mark.svg` - отдельный знак на графитовом фоне.
- `turistika-icon.svg` - иконка на светлом фоне для интерфейсов и карты.
- `turistika-favicon.svg` - упрощенная favicon/app icon.

Концепция: стилизованная буква `Т` как маршрут, геометка и компас. Без локальных символов, этнических мотивов, гор, солнца, деревьев и региональных образов.

Слоган: `Твоя карта впечатлений`.
